## 4. Critical Standing Rule

> **Do not change database schema, Prisma schema, or production data without explicit user approval.**

- Never add `@@unique` constraints without first checking production data for duplicates (learned from `62bc662` rollback — prod had duplicate receipt numbers from import)
- Never run `prisma db push` in production without approval
- Always run `npx tsc --noEmit` before committing any API routes or server actions that touch Prisma types
- Auto-push is configured: every `git commit` automatically triggers `git push` via PostToolUse hook in `.claude/settings.local.json`

## 6. Member Profile UI Phase 1 — Completed Changes

**Files changed:** `components/members/MemberDetail.tsx`, `app/(dashboard)/(crm)/members/[id]/page.tsx`, `components/members/EditMemberButton.tsx`

### What changed:

1. **Card order on mobile** — Membership card appears first on mobile (most useful for daily staff), Identity card second. Swapped via CSS `order` classes (`order-1 lg:order-2` / `order-2 lg:order-1`) — desktop layout unchanged. Required changing `space-y-4` to `flex flex-col gap-4` on the left column for `order` to work.

2. **Action buttons — solid colours** — Check In changed from ghost emerald outline to `bg-emerald-500 hover:bg-emerald-600 text-white`. Record Payment changed from ghost violet to `bg-orange-500 hover:bg-orange-600 text-white`. Both are much more tappable on mobile.

3. **Full-width mobile buttons** — Added `flex-1 sm:flex-none justify-center` to Check In and Record Payment so they fill available width side-by-side on mobile.

4. **Edit Details tap target** — `py-1.5` → `py-2` in `EditMemberButton.tsx`.

5. **Status badge capitalisation** — Added `STATUS_LABELS` map so badge shows "Active / Expired / Frozen" instead of raw enum `ACTIVE / EXPIRED / FROZEN`.

6. **Removed 3× inner scroll traps** — Removed `max-h-52 overflow-y-auto` from attendance list, `max-h-64 overflow-y-auto` from payment history, `max-h-48 overflow-y-auto` from membership history. All lists now expand fully; page-level scroll handles everything.
